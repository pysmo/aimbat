# Recipes

AIMBAT exposes its functionality through both a CLI and a Python API. The CLI
combines well with common shell tools, while the API gives programmatic access
to the same functionality.

The recipes on this page show that flexibility in practice. They aren't
showcases of advanced features, just practical starting points for custom
workflows.
